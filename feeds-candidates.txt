# 使い方:
#   1) フィードURLが分からないサイトは、探して試すところまで一度に
#      python -m freming.cli discover-feed --probe https://example.com/

#      python -m freming.cli probe-feed <URL...>
#   3) 「候補N件」が出たものを config.yaml の editorial_sources に登録する
#
#   まとめて走らせる: bash scripts/find_sources.sh
