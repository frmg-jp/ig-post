## 物件を選ぶ基準（スコアリングに効かせる）

### 1. 前歴が「目に見える形で」残っている ★最重要

単に「用途転換された」ではなく、**転換前の正体が視覚的に読み取れる**ことが決定的。

- 壁面のゴーストサイン（003 "ORIENTAL WAREHOUSE"、004 "EOFF ELECTRIC COMPANY"）
- 用途固有の部材が現役（005 消防車用アーチ扉、008 時計文字盤が窓）
- 構造の露出（木トラス、鋳鉄柱、露出レンガ、ブリキ型押し天井）

「元○○」と一言で説明でき、その証拠が写真に写っている物件が通っている。
逆に、内装だけ綺麗にリノベされて前歴が消えた物件は1件もない。

### 2. 時代・様式が特定できる

MCM、スパニッシュコロニアル、クラフツマン、19世紀の産業建築。
**様式不明の現代建売・新築マンションはゼロ。** 築年と様式が言えることが前提。

### 3. 一点物である

同一仕様が複数存在する物件（新築分譲、タワーマンションの1住戸）は含まれない。
008 は集合住宅内の1戸だが、時計塔という唯一無二の要素を持つ。

### 4. 立地が物語の一部になっている

- 001: 花崗岩の山塊の直下という異常な立地そのものが主題
- 004: Pearl District の街区ごと俯瞰で見せる
- 002/006/007: 丘陵地の植生に埋もれる関係

「どこにあるか」が写真の主題になりうる物件。

### 5. エリア（重点エリアは加点、必須ではない）

実例は LA周辺4 / SF 1 / Portland 1 / Chicago 1 / Brooklyn 1。

当初 Chicago / Brooklyn は重点エリアに入っていなかったが、承認実績を受けて
`focus_areas` に追加した（Chicago: West Loop / Wicker Park / Logan Square、
New York: DUMBO / Brooklyn / Williamsburg / Tribeca）。いずれも 19世紀〜20世紀初頭の
産業建築ストックが厚く、adaptive_reuse の供給源として LA / SF / Portland と同格に扱う。

これで実例8件はすべて重点エリア内に収まったが、**エリアは加点要素であり
足切り条件にはしない**方針は維持する。物語性が十分に強ければエリア外でも
承認しうる（Chicago / Brooklyn 自体がその実例だった）。

## 画像を選ぶ基準（[4] 画像取得に効かせる）

### 1枚目（サムネイル）
建物の「正体」が一目で分かるカットを選ぶ。優先順は以下。

1. 前歴を示す外観（ゴーストサイン、特徴的な開口部）— 003/004/005
2. 立地との関係が分かる引きの外観 — 001/006/007
3. その物件を象徴する内部空間 — 002/008

### 2枚目以降
- **素材が主役のカット**を優先（露出レンガ、木トラス、石積み、ブリキ天井、無垢材）
- 引き（空間全体）と寄り（ディテール）を混ぜる
- **生活の痕跡があるもの**を選ぶ。家具・本・植物が入った状態。空室のがらんどうな写真は避ける
- 自然光。明るく、彩度は誇張しない

### 除外
- 人物が写っているもの
- 文字やロゴが焼き込まれたもの（不動産会社のウォーターマーク等）
- 間取り図、地図、航空写真のみのもの
- 極端に暗い／手ブレしているもの
- 同じ構図の重複

## 未確認の点

- 価格帯は画像から判断できない。承認済み物件の実際の価格が分かれば、
  価格の重み（現状 0.05）の妥当性を検証したい
- 8件はいずれも英語圏。ポルトガル／スペイン／台湾の承認実績がまだない
